# 弓道部 道場打刻・出欠管理（第1段階）

道場の入口に貼ったQRコードを、部員がスマホの専用アプリで読み取るだけで入室・退室を記録します。記録はGoogleスプレッドシートに残り、遅刻・欠席を自動で判定します。費用は0円です。

## 公開先（第1版・2026-11-26）
- アプリ：https://s245028.github.io/kyudo-dakoku/ （GitHub リポジトリ s245028/kyudo-dakoku の index.html）
- API（Apps Script ウェブアプリ・バージョン1）：https://script.google.com/macros/s/AKfycbx_9LDL62Fhepa6i4pNS34m3c-ch85_vN6BeJfSen34Cjy-px2y0oTyk-eGA1pRYLtp/exec
- Code.gs を直したら「デプロイを管理」で同じデプロイの新バージョンにする（URLを変えないため）
- index.html を直したら GitHub のリポジトリへ上書きアップロード

## 判定ルール（練習ルールシートで変更できます）

| 曜日 | 条件 | 区分 | 遅刻基準 | 練習開始 |
|---|---|---|---|---|
| 月・火・木 | 4・5コマなし | 前半 | 17:00 | 17:30 |
| 月・火・木 | 4コマあり | 前半 | 17:30 | 17:30 |
| 月・火・木 | 5コマあり | 後半 | 19:15 | 19:45 |
| 土 | 全員 | 全体 | 08:20 | 09:15 |

- その日の**最初の入室**が遅刻基準を1秒でも過ぎたら遅刻です（遅刻の分数は切り上げ）。
- 選考期間も同じルールです。
- 何度出入りしても、遅刻の判定に使うのは最初の入室だけです。

## セットアップ（管理者）

### 1. スプレッドシートとApps Script
1. Googleドライブで**空のスプレッドシート**を作る（名前は「弓道部 出欠管理」など）。
2. メニューの **拡張機能 → Apps Script** を開く。
3. 最初からある `コード.gs` の中身をすべて消し、`Code.gs` の中身を貼り付けて保存する。
4. 左の歯車（プロジェクトの設定）→「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェックを入れる。エディタに出てきた `appsscript.json` を、このフォルダの `appsscript.json` の中身に置き換えて保存する。
5. 関数の選択欄で `setup` を選んで **実行** し、権限を許可する。
6. スプレッドシートに戻って再読み込みすると、シートと「出席管理」メニューができています。

### 2. ウェブアプリとして公開
1. Apps Scriptの右上で **デプロイ → 新しいデプロイ → 種類：ウェブアプリ** を選ぶ。
2. 次のユーザーとして実行：**自分**／アクセスできるユーザー：**全員** にしてデプロイする。
3. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピーする。

> Code.gsを書き換えたときは、**デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン** で更新します。URLは変わりません。

### 3. 打刻アプリの公開（GitHub Pages）
1. `index.html` の `API_URL` を、2でコピーしたURLに書き換える。
2. GitHubで新しいリポジトリを作り、`index.html` を置く。
3. **Settings → Pages** で、公開元を `main` ブランチにする。
4. 公開されたURL（`https://ユーザー名.github.io/リポジトリ名/`）を、スプレッドシートの**設定シートの「アプリURL」**に入れる。

### 4. 初期データ
1. **設定シート**：道場の**緯度・経度**を入れる（Googleマップで道場を長押しすると表示されます）。空欄のままだと位置チェックをしません。
2. 入口QR（`入口QR_印刷用.png`、またはメニューの **出席管理 → 入口QRを表示**）を印刷し、道場の入口に貼る。
3. **アプリのURL**（GitHub PagesのURL）を部のLINEグループなどに貼る。部員名簿は空のままで構いません。部員がアプリから自分で登録します。

## 部員がやること（初回だけ）

1. 部のグループに貼られたアプリのURLをスマホで開く。
2. **先にホーム画面に追加**し、ホーム画面のアイコンから開き直す。iPhoneはSafariとホーム画面のアプリで保存場所が別なので、この順番が大事です。
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：右上のメニュー →「ホーム画面に追加」
3. アプリの**部員登録**画面で、学生番号・名前・性別・学年を入力して登録する。
4. 続けて出てくる「コマ表」で、授業がある曜日・コマにチェックを入れて保存する。
5. 主将が承認するまでは「承認待ち」と表示されます。承認されたら打刻できます。カメラと位置情報の利用は**許可**してください。

**毎回**：アイコンを開く → 入口のQRにかざす → 「入室 16:58」と表示されたら完了。帰るときも同じQRを読むと退室になります。

## 引退した人（参加連絡制）

- 部員名簿の**状態**は「現役／引退／休部・退部／卒業」。判定は学年ではなく状態で決まります。
- **現役**：練習日は毎回、遅刻・欠席を判定します。
- **引退**：アプリの打刻画面に出る「参加する練習日」で**参加する**を押した日だけ判定します（現役と同じく、来なければ無断欠席、遅れたら遅刻の罰）。押していない日は判定せず、来ても罰はつきません（出欠一覧には「参加（登録なし）」と残る）。
  - 参加の登録は**集合時刻まで**、取り消しは**集合の1時間前まで**（連絡の締め切りと同じ）。それより後に来られなくなったら主将に連絡し、主将が臨時変更シートに「欠席連絡済」と連絡日時を入れる。
  - 登録は臨時変更シートに「参加」の行として残ります（主将が手で入れても同じ扱い）。
- **休部・退部／卒業**：打刻できず、判定もしません。記録は残ります。
- 引退しても、残っている罰はそのまま残ります。

## 代替わり・年度替わり

| 時期 | 操作 | 内容 |
|---|---|---|
| 10月ごろ（引退・役職交代） | メニュー **出席管理 → 代替わり（引退・役職の交代）** | 引退する学年（例：3年）の現役部員を一括で「引退」にし、引退日を記録。新しい主将・副務の学生番号を入れると役職も入れ替わる（引退する人の役職は外れる） |
| 4月（学年の繰り上げ） | メニュー **出席管理 → 学年を1つ上げる（4月）** | 1→2→3→4年、院1→院2年。4年・院2年は「卒業」に。現役・引退の状態は変わらない（新3年生は現役のまま）。**年1回だけ**実行 |
| 4〜5月（新入生） | — | 新入生がアプリで登録 → 主将が承認 |

- 大学院に進んで続ける人は、繰り上げのあとで学年と状態を手で直してください。
- 引退日より前の日を判定し直すときは、その人を現役として判定します。

## 罰のルール

- 自動でつく罰：**遅刻**（連絡なし）、**無断欠席**、**遅刻（連絡遅れ）**、**欠席（連絡遅れ）**。連絡が集合時間の1時間前までにあった遅刻・欠席は罰なし。
- 副務がつける罰：**私物の出しっぱなし**、**その他**（メモ必須）。種類は罰の種類シートで増やせます。
- 罰の数：罰の種類シートの「基本の数」（最初はすべて1個）から始まり、ついた日から7日ごとに**残っている数が2倍**になります（1→2→4→8…）。倍になる日の前日までに消化した分は、倍になる前に差し引きます。残りが0になったら消化済みです。
  - 例：1個の罰が8日目に2個になり、9日目に1個消化すると残り1個。14日目に残り1個が2倍になって2個。
- 罰1個に、やることが1つ割り当てられます。やることは**罰の割り当て**シートに、割り当てた日・割り当てた人・消化した日・確認した人と一緒に残ります（消しても記録は残る）。
- 部員はアプリの「罰」タブで、自分のやること（例：「・窓のサッシの掃除」）を確認できます。まだ割り当てられていない罰は「やることは副務が決めます」と表示されます。
- **罰の集計**シートには、部員ごとの累計件数・残りの数・理由別の件数が自動で出ます。
- 出欠一覧の「手動判定」を直して **出席管理 → 日付を指定して判定** を実行すると、その日の自動の罰も付け直されます（消化済みと副務がつけた罰はそのまま）。
- 連絡日時が空欄のときは「締め切り内」として扱い、備考にその旨が出ます。

## 主将・管理者の運用

| やりたいこと | 方法 |
|---|---|
| 登録した部員を承認する | 部員名簿で、承認待ちの行は黄色になります。本人と確認できたら「承認」にチェックを入れる |
| 休部・退部・引退を手で変える | 部員名簿の「状態」を選び直す（引退にするときは引退日も入れると、その日から引退扱い） |
| スマホを替えた部員を登録し直させる | 部員名簿のその人の「識別キー」を消す → 本人がアプリから同じ学生番号で登録 → もう一度承認 |
| コマ表を確定する | 設定シートの「コマ表ロック」にチェックを入れる（部員はアプリから変更できなくなる） |
| 休講・補講（その人のその日だけ） | 臨時変更シートに「日付・学生番号・内容（4・5コマなし／4コマあり／5コマあり）」を入れる |
| 部活が休みの日 | 臨時変更シートに日付と「休み」を入れ、学生番号は空欄にする |
| 事前に連絡があった欠席・遅刻 | 臨時変更シートに「欠席連絡済」または「遅刻連絡済」と、連絡を受けた日時（例：2026-12-01 15:40）を入れる。1時間前までなら罰なし、過ぎていたら「連絡遅れ」で罰 |
| 判定を手で直す | 出欠一覧の「手動判定」と「修正理由」を入れる（再判定しても残ります。「最終判定」列に反映） |
| 今いる人を見る | 在室状況シート、またはアプリの「在室」タブ |
| 判定を今すぐ更新する | メニューの **出席管理 → 今日の出欠を判定** |

- 承認していない部員と、休部・退部・卒業の部員は打刻できず、出欠一覧にも載りません。
- 毎晩22:00に、退室していない人を**自動退室**にし、その日の出欠を判定します。退室の打ち忘れは備考に「退室打刻なし」と出るだけで、遅刻・欠席には影響しません。
- 打刻ログは**消さない・書き換えない**でください。判定の根拠になります。誤りは出欠一覧の手動判定で直します。

## 二重読み取り・取り消し
- 同じ人が2分以内にもう一度読んでも無視します（設定シートで変更可）。
- 読み取った直後の画面に出る「取り消す」ボタンで、60秒以内なら自分の打刻を取り消せます。

## 注意
- 入口QRの画像は、無料のQR作成サービス（api.qrserver.com）で生成しています。
- 位置チェックは、GPSの誤差（最大200m）を考慮して判定します。屋内で弾かれることが多い場合は、設定の「許容距離(m)」を広げてください。
