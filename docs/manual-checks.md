## 切り替え（P6）の前に必要なこと

- 匿名ログインは、同じ回線から1時間に30回までが初期値。部員が道場の Wi-Fi で一斉に登録する場合は、本番プロジェクトの **Authentication → Rate Limits** で上限を上げる。
- 本番プロジェクトを作り、マイグレーション、Edge Functions、README の初期設定の SQL（3つ）を適用する。
- Vercel の **Production** の環境変数と、GitHub の Actions の変数を本番の値に変える。
- 本番プロジェクトには開発用の管理者を作らない（`admins` 表は空のままにする）。
- バックアップの保存先を決める（計画書11章）。CSV の書き出し以外の自動バックアップはまだない。
